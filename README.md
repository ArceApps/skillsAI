# SkillsAI

Repositorio centralizado de habilidades (skills) para agentes de IA, diseñado para modularizar y potenciar capacidades de desarrollo, testing, gestión y diseño.

## 📂 Estructura del Proyecto

El repositorio está organizado en categorías funcionales:

*   **`/mobile-aso`**: Optimización para App Store y gestión de changelogs.
*   **`/qa-testing`**: Frameworks y estrategias de testing (Mobile, Unit, E2E).
*   **`/project-management`**: Gestión de issues, planes y GitHub Projects.
*   **`/development-workflow`**: Herramientas para documentación y automatización.
*   **`/product-design`**: Diseño de dashboards y herramientas de productividad.

## 📄 Documentación Clave

*   **[AGENTS.md](./AGENTS.md)**: Inventario completo y detallado de todas las skills disponibles.
*   **[TESTING_SKILLS_ANALYSIS.md](./TESTING_SKILLS_ANALYSIS.md)**: Análisis comparativo de las skills de testing con enfoque en desarrollo Android.

## 🚀 Uso

Estas skills están diseñadas para ser consumidas por agentes de IA para asistir en tareas específicas de ingeniería de software.
